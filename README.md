# ohmyswitch

Provider-first config manager for AI coding harnesses.

## 环境要求

- Node.js 24.13+
- pnpm v12

## 开发

```sh
pnpm install
pnpm dev
```

## 常用命令

```sh
pnpm typecheck      # 类型检查
pnpm lint           # Biome 检查
pnpm format         # 格式化
pnpm build          # 构建主进程和界面
pnpm package        # 打包为未签名的本地应用（dist/）
pnpm ui:add <name>  # 添加 shadcn/ui 组件
```
